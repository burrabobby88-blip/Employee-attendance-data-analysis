# Employee-attendance-data-analysis
Python-based Employee Attendance Data Analysis System for dataset generation, data cleaning, attendance status analysis, and visualization.
# Project Documentation

## Project Name
Employee Attendance Data Analysis System

## Purpose
To analyze employee attendance records and demonstrate data cleaning techniques using Python.

## Data Cleaning
- Identified missing values.
- Filled numerical missing values using median.
- Filled categorical missing values using mode.
- Removed duplicate records.

## Analysis
Analyzed Present, Absent, Late, and Leave records before and after cleaning.

## Tools
Python, Pandas, NumPy, and Matplotlib.

## Expected Outcome
A cleaned attendance dataset with no missing values or duplicate rows, along with attendance summaries and visualizations.

## Limitation
The project uses synthetically generated sample data for academic demonstration.
